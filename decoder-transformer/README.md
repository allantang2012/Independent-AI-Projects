# Decoder-Only Transformer From Scratch

An independent AI learning project focused on implementing
and training a GPT-style decoder-only transformer using PyTorch.

## Goals
- Implement character-level tokenization
- Build causal self-attention and multi-head attention
- Implement transformer decoder blocks
- Train a language model on Tiny Shakespeare
- Evaluate training and validation loss
- Experiment with model architectures and hyperparameters

## Technologies
- Python 3.11
- PyTorch
- Apple Silicon GPU (MPS)
